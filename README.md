# 📊 Portfolio Tracker | Power BI & Excel

An interactive investment portfolio tracking solution built with **Microsoft Power BI and Excel**, designed to simplify investment monitoring and financial performance analysis.

## 🚀 How It Works

The solution requires minimal manual input. Users only need to register their stock transactions in the provided Excel file:

- **Buy** — Record stock purchases.
- **Sell** — Record stock sales.
- **Dividend** — Record dividend payments received.

Once the Excel data is updated and the Power BI dataset is refreshed, the dashboard automatically calculates and visualizes portfolio metrics.

## 📈 Key Features

- Automated investment portfolio calculations
- Stock holdings and transaction tracking
- Portfolio performance and return analysis
- Dividend income monitoring
- Historical investment performance
- Interactive charts and financial insights

## 🛠️ Technologies

- Power BI
- DAX
- Power Query
- Microsoft Excel
- Data Modeling

## 📂 Getting Started

1. Download the Excel source file and Power BI report.
2. Open the Excel file and enter your stock transactions.
3. Open the Power BI report in Power BI Desktop.
4. Configure the Excel source path if necessary.
5. Refresh the data to update all calculations and visualizations.

**No manual calculations are required — simply maintain your transactions and let Power BI handle the analysis.**
